# waledsobhyt4-ui

Made by **WaledSobhYT**

## Features

- **Noclip** – You don't die when hitting obstacles
- **Infinity Jump** – Unlimited jumps (you can always jump)
- **Bot** – Simple auto-jump / click spam bot

All features can be toggled in the mod settings.

## How to use

1. Install the mod via Geode
2. Go to **Geode → Installed → waledsobhyt4-ui → Settings**
3. Enable the features you want
4. Play any level
